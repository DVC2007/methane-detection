# AI assistance record

AI may explain concepts, suggest structure, generate small code drafts, write tests, improve wording, and help debug reproduced errors. Students must decide the research question, dataset suitability, labels, preprocessing, evaluation design, and interpretation. Never ask AI to invent measurements, citations, data sources, model performance, or field observations. Verify generated code with tests and a small manual example. Do not paste credentials, personal information, or restricted data into AI tools.
